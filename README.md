# Business Command Center

Yksityinen johtamisen keskipiste. Etusivu kokoaa kaikista suunnitelmista sen, mitä pitää tehdä tänään. Suunnitelmat koostuvat moduuleista, ja sisältöä muokataan suoraan sivulla Muokkaa-painikkeesta. Tiedot ovat Supabasessa, ja pääsy on Cloudflare Accessin takana.

Kehitys: `npm install`, `npm test`, `npm run dev`. Tarkemmat ohjeet ovat tiedostossa `CLAUDE.md`.
