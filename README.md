# Business Command Center

Yksityinen suunnittelu- ja johtamisalusta. Suunnitelmat koostuvat moduuleista, ja sisältöä muokataan suoraan sivulla Muokkaa-painikkeesta. Tiedot ovat Supabasessa, ja pääsy on Cloudflare Accessin takana.

Kehitys: `npm install`, `npm test`, `npm run dev`. Tarkemmat ohjeet ovat tiedostossa `CLAUDE.md`.
